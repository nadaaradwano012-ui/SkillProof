# 🚀 Khatwa (خُطوة) - Internship Skill Gap Matcher

**Khatwa** is a dynamic career preparation platform built with React. It empowers university students to transition smoothly from academia to the real-world job market by analyzing their skill gaps, providing actionable roadmaps, and helping them build an evidence-backed interactive portfolio.

This project was developed as a graduation project for the **Digital Egypt Pioneers Initiative (DEPI)** - Frontend Web Development Track.

## 🎯 The Problem It Solves
Students often read job/internship descriptions without knowing how well they fit the role or what exactly they need to improve. Standard CVs fail to provide *proof* of skills, leaving recruiters guessing and students frustrated.

## 💡 The Solution
Khatwa shifts the narrative from "I think I know React" to "I can prove my React skills with these verified projects." It acts as a personal career navigator with highly interactive UIs.

## ✨ Core Features (Frontend Highlights)
- **📊 Visual Skill Gap Analysis:** Utilizes interactive radar charts to compare a student's current skill set against specific internship requirements.
- **🗺️ Personalized Roadmaps:** Dynamic, step-by-step learning paths generated to help students fill their specific skill gaps.
- **📁 Evidence-Based Portfolio:** A feature that allows users to attach concrete evidence (GitHub links, deployed projects, certificates) to individual skills.
- **📌 Kanban Application Tracker:** An intuitive Drag & Drop board (Applied → Interview → Accepted) to manage ongoing internship applications.
- **🎨 Gamified & Responsive UI:** Built with modern CSS frameworks and animation libraries to ensure a seamless, engaging, and fully responsive user experience.

## 🛠️ Tech Stack
- **Framework:** React.js (Hooks, Functional Components)
- **Styling:** Tailwind CSS / Material-UI 
- **Animations & Interactions:** Framer Motion
- **Data Visualization:** Recharts / Chart.js
- **State Management:** Context API / Redux (or whatever you plan to use)
- **Routing:** React Router v6
- **Drag & Drop:** dnd-kit / react-beautiful-dnd

## 🚀 Future Enhancements (Beyond MVP)
- Real-time AI integration for extracting skills directly from uploaded CV PDFs.
- Interview preparation module with simulated AI feedback.
- Recruiter dashboard to match companies directly with evidence-backed student profiles.
